\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class Tensor\+Data$<$ T $>$}
Internal storage class for tensor data and metadata.

\doxylink{classTensorData}{Tensor\+Data} manages the raw memory allocation, the shape of the tensor, and the memory strides. It uses std\+::shared\+\_\+ptr for automatic memory management on the CPU. For GPU, a separate memory management strategy would be needed.

This class is designed to be wrapped by \doxylink{classTensorWrapper}{Tensor\+Wrapper}, which provides the high-\/level API.
