\subsubsection*{template$<$typename T$>$\newline
class hahaha\+::ml\+::\+Optimizer$<$ T $>$}
Base class for all optimizers.

An optimizer updates the parameters of a model based on the computed gradients. It manages a list of parameters and provides a \doxylink{classhahaha_1_1ml_1_1Optimizer_a4e0b41bcdf049ff6bcee9aec6e736987}{step()} method for performing the update logic.
