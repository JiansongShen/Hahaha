Broadcast tensor to match the shape of another tensor.

This operation does NOT allocate new storage. It returns a view. Broadcasted axes are represented by setting stride\mbox{[}axis\mbox{]} = 0. Reading element at coordinate {\ttfamily idx} uses\+: linear = sum(idx\mbox{[}d\mbox{]} \texorpdfstring{$\ast$}{*} stride\mbox{[}d\mbox{]}) value = base\+\_\+ptr\mbox{[}linear\mbox{]}

Example\+:
\begin{DoxyItemize}
\item self.\+shape = (1, 3), self.\+stride = (3, 1)
\item new\+Shape = (2, 3)
\item result.\+stride becomes (0, 1)
\item So result\mbox{[}0, j\mbox{]} and result\mbox{[}1, j\mbox{]} map to the same source element.
\end{DoxyItemize}
