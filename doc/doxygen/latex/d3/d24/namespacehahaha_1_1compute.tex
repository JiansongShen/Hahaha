Broadcast a node to a target shape (view semantics).

Forward (plain text)\+:
\begin{DoxyItemize}
\item The output is a view of the same underlying storage.
\item Broadcasted dimensions are represented by stride = 0, so repeated reads map to the same source element.
\end{DoxyItemize}

Backward (plain text)\+:
\begin{DoxyItemize}
\item Let y = broadcast(x) with y.\+shape = target.
\item Upstream gradient is d\+L/dy.
\item Gradient for x is a reduction over broadcasted axes\+: d\+L/dx = sum(d\+L/dy, axes=broadcasted\+\_\+axes, keep\+Dims=rank\+\_\+equal)
\end{DoxyItemize}

Example\+:
\begin{DoxyItemize}
\item x.\+shape = (3), y.\+shape = (2,3)
\item broadcasted\+\_\+axes = \{0\}
\item d\+L/dx\mbox{[}j\mbox{]} = d\+L/dy\mbox{[}0,j\mbox{]} + d\+L/dy\mbox{[}1,j\mbox{]}
\end{DoxyItemize}
