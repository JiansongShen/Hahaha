\subsubsection*{template$<$typename T$>$\newline
struct Nested\+Data$<$ T $>$}
Utility structure for handling nested initializer lists to initialize tensors.

\doxylink{structNestedData}{Nested\+Data} recursively flattens multi-\/dimensional initializer lists into a 1D vector while keeping track of the tensor\textquotesingle{}s shape.

Example\+: \doxylink{structNestedData}{Nested\+Data$<$float$>$} data = \{\{1, 2\}, \{3, 4\}\}; // flat\+Data\+\_\+ becomes \{1, 2, 3, 4\}, shape\+\_\+ becomes \{2, 2\}
