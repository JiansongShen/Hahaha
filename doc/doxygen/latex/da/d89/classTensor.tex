\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class Tensor$<$ T $>$}
Forward declaration of the high-\/level \doxylink{classTensor}{Tensor} class.

High-\/level User Interface for \doxylink{classTensor}{Tensor} operations and Autograd.

This class acts as a handle to a Compute\+Node in the computational graph. It provides operator overloading (+, -\/, \texorpdfstring{$\ast$}{*}, /) which automatically builds the graph in the background (Dynamic Graph / Define-\/by-\/\+Run).

Usage\+: \doxylink{classTensor}{Tensor$<$float$>$} a(\{2, 2\}, 1.\+0f); \doxylink{classTensor}{Tensor$<$float$>$} b(\{2, 2\}, 2.\+0f); auto c = a + b; c.\+backward(); // Propagates gradients back to a and b
