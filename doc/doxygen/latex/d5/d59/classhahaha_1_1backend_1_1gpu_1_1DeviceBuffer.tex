\doxysubsection{Detailed Description}
RAII handle for a GPU device buffer.

This stores the device address as an integer to avoid exposing raw pointers in the backend public API. The buffer is automatically deallocated when the \doxylink{classhahaha_1_1backend_1_1gpu_1_1DeviceBuffer}{Device\+Buffer} is destroyed or moved from.
