\doxysubsection{Detailed Description}
Thread-\/safe asynchronous logging system.

\doxylink{classLogger}{Logger} uses a background worker thread and a message queue to ensure that logging calls do not block the main execution thread. It supports both console and file output with configurable levels and formatting.

Use the static methods (info, warn, error, etc.) for convenient logging.
