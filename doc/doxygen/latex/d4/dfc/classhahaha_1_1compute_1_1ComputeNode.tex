\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class hahaha\+::compute\+::\+Compute\+Node$<$ T $>$}
Represents a node in the computational graph.

Each \doxylink{classhahaha_1_1compute_1_1ComputeNode}{Compute\+Node} manages a piece of tensor data and its role in the graph, including its parents (input nodes), the operator that produced it, and the logic for backpropagation (grad\+Fun).

In a dynamic computational graph\+:
\begin{DoxyItemize}
\item Nodes are created during the forward pass.
\item Gradients are propagated during the backward pass using the chain rule\+: d\+L/dx = d\+L/dz \texorpdfstring{$\ast$}{*} dz/dx
\end{DoxyItemize}

Plain-\/text formulas\+:
\begin{DoxyItemize}
\item Forward computes intermediate tensors, e.\+g. z = f(x, y).
\item Backward propagates gradients using the chain rule\+: d\+L/dx = (d\+L/dz) \texorpdfstring{$\ast$}{*} (dz/dx) d\+L/dy = (d\+L/dz) \texorpdfstring{$\ast$}{*} (dz/dy)
\item When a node is used multiple times, gradients accumulate\+: grad\+\_\+total = sum(grad\+\_\+contrib\+\_\+k)
\end{DoxyItemize}

Triggers the backward pass starting from this node.

If this is the output node (e.\+g., Loss), its gradient is initialized to 1.\+0 (d\+L/dL = 1). Then it calls its grad\+Fun to propagate gradients to parents.

Plain-\/text formulas\+:
\begin{DoxyItemize}
\item For the root node (Loss), initialize upstream gradient as\+: d\+L/d\+Loss = 1

\end{DoxyItemize}
