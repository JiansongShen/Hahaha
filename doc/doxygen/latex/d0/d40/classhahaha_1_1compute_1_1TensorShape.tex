\doxysubsection{Detailed Description}
Represents the shape (dimensions) of a tensor.

\doxylink{classhahaha_1_1compute_1_1TensorShape}{Tensor\+Shape} stores a vector of integers representing the size of each dimension. For example, a 2x3 matrix has dimensions \{2, 3\}.

This class provides utilities to compute the total number of elements and format the shape as a string.
