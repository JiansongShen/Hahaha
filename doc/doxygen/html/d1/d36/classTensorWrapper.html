Detailed Description

template<typename T>
class TensorWrapper< T >

Main Tensor class providing a high-level API for numerical operations.

This class wraps TensorData and provides a comprehensive set of operations including basic arithmetic, matrix multiplication, and reshape capabilities. It is designed to work with automatic differentiation and computational graphs.

Template Parameters
TThe numeric type of the tensor elements.

◆ broadcastTo()

template<typename T>
TensorWrapper hahaha::math::TensorWrapper< T >::broadcastTo ( const TensorShape & newShape)
inline

Broadcast tensor to match the shape of another tensor.

This operation does NOT allocate new storage. It returns a view. Broadcasted axes are represented by setting stride[axis] = 0. Reading element at coordinate idx uses: linear = sum(idx[d] * stride[d]) value = base_ptr[linear]

Example:

  • self.shape = (1, 3), self.stride = (3, 1)
  • newShape = (2, 3)
  • result.stride becomes (0, 1)
  • So result[0, j] and result[1, j] map to the same source element.
Parameters
newShapeThe target tensor shape for broadcasting.
Returns
TensorWrapper A new tensor that has the target shape but shares data with this one.
Exceptions
std::invalid_argumentif newShape is not broadcast-compatible, or if newShape rank is smaller than current rank.
