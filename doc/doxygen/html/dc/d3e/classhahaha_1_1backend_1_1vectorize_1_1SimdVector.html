Detailed Description

template<typename T, size_t Width>
class hahaha::backend::vectorize::SimdVector< T, Width >

Represents a fixed-size vector for SIMD operations.

This class abstracts away architecture-specific SIMD types and operations.

Template Parameters
TThe numeric type of elements.
WidthThe number of elements in the SIMD vector.
