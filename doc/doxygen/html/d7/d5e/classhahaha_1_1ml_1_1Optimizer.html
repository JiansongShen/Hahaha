Detailed Description

template<typename T>
class hahaha::ml::Optimizer< T >

Base class for all optimizers.

An optimizer updates the parameters of a model based on the computed gradients. It manages a list of parameters and provides a step() method for performing the update logic.

Performs a single optimization step (parameter update).

This method must be implemented by concrete optimizer subclasses. It iterates through the parameters and updates their values using their gradients.
