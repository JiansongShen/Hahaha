Detailed Description

template<typename T>
class hahaha::Tensor< T >

Forward declaration of the high-level Tensor class.

High-level User Interface for Tensor operations and Autograd.

This class acts as a handle to a ComputeNode in the computational graph. It provides operator overloading (+, -, *, /) which automatically builds the graph in the background (Dynamic Graph / Define-by-Run).

Usage: Tensor<float> a({2, 2}, 1.0f); Tensor<float> b({2, 2}, 2.0f); auto c = a + b; c.backward(); // Propagates gradients back to a and b
