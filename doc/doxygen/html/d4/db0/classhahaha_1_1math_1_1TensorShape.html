Detailed Description

Represents the shape (dimensions) of a tensor.

TensorShape stores a vector of integers representing the size of each dimension. For example, a 2x3 matrix has dimensions {2, 3}.

This class provides utilities to compute the total number of elements and format the shape as a string.

Compute the broadcast-compatible shape for two tensor shapes.

Two shapes are broadcast-compatible if, for each dimension, they are either equal or one of them is 1. The result shape has the maximum size in each dimension.

Parameters

shape2Second tensor shape.
Returns
