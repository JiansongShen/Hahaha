Convenience function for creating an expected value (success case).

Convenience function for creating an expected value (success case). This helper function wraps a value in std::expected<T, E> to indicate a successful operation result.

Template Parameters
TThe value type (result type when successful).
EThe error type (type of error when operation fails).
Parameters
valThe value to wrap in an expected result.
Returns
std::expected<T, E> An expected value containing the moved value.
auto result = ok<int, std::string>(42);
if (result.has_value()) {
std::cout << *result << std::endl; // Prints 42
}

namespace hahaha::common {
template <typename T, typename E> auto ok(T val) {
return std::expected<T, E>(std::move(val));
}
template <typename E> auto err(E err) {
return std::unexpected(std::move(err));
}
} // namespace hahaha::common
