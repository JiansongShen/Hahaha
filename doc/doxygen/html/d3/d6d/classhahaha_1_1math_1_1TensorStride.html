Detailed Description

Represents the memory strides of a tensor.

Strides define how many elements to skip in memory to move to the next element in a specific dimension.

For a row-major tensor of shape (d0, d1, ..., dN):

  • stride[N] = 1
  • stride[i] = stride[i+1] * dims[i+1]
