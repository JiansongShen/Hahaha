Hahaha is an {\bfseries{education-\/first}} numerical computing and machine learning library written in {\bfseries{C++23}}. It aims to provide a {\bfseries{clear, inspectable implementation}} of tensors, automatic differentiation, and training loops, together with {\bfseries{visualization tooling}} so learners can {\itshape see} what happens during training.\hypertarget{md_README_autotoc_md1}{}\doxysection{\texorpdfstring{What this project is for}{What this project is for}}\label{md_README_autotoc_md1}

\begin{DoxyItemize}
\item {\bfseries{Learning}}\+: read the code and understand how tensors, broadcasting, and autograd work end-\/to-\/end.
\item {\bfseries{Teaching / Demos}}\+: run examples that visualize the training process (loss curves, parameter updates, etc.).
\item {\bfseries{Small experiments}}\+: simple models and datasets (e.\+g. MNIST) without depending on a large framework.
\end{DoxyItemize}\hypertarget{md_README_autotoc_md2}{}\doxysection{\texorpdfstring{Key features}{Key features}}\label{md_README_autotoc_md2}

\begin{DoxyItemize}
\item {\bfseries{Tensor core}}\+: {\ttfamily Tensor} / {\ttfamily Tensor\+Wrapper} with shape ({\ttfamily Tensor\+Shape}), stride ({\ttfamily Tensor\+Stride}), broadcasting, reshape, transpose, and basic math.
\item {\bfseries{Autograd + compute graph}}\+: define-\/by-\/run graph building via {\ttfamily compute/graph/\texorpdfstring{$\ast$}{*}} and backward propagation with unit tests.
\item {\bfseries{Broadcasting as a first-\/class op}}\+: explicit {\ttfamily Broadcast} node with correct gradient reduction.
\item {\bfseries{Visualization + educational UX}}\+:
\begin{DoxyItemize}
\item Im\+Gui-\/based visualizer and demos under {\ttfamily examples/} to show training dynamics.
\item Code is intentionally written to be readable and traceable, with tests as executable documentation.
\end{DoxyItemize}
\item {\bfseries{Tooling}}\+: Meson + Ninja build, Google\+Test, formatting script {\ttfamily python3 dev/format.\+py}.
\end{DoxyItemize}\hypertarget{md_README_autotoc_md3}{}\doxysection{\texorpdfstring{Build and run}{Build and run}}\label{md_README_autotoc_md3}
